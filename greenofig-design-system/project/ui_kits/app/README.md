# App UI Kit

A pixel-faithful recreation of the GreenoFig client web app — covers the dashboard, AI Coach chat, meal plans, and messages.

## What's in here
- `index.html` — interactive prototype with sidebar nav between 4 screens
- `AppShell.jsx` — collapsible sidebar + topbar layout
- `Sidebar.jsx` — nav with logo, sections, footer
- `Topbar.jsx` — search, notifications, avatar
- `Dashboard.jsx` — stat cards, today's plan, streak, quick actions
- `AICoach.jsx` — chat interface with assistant
- `MealPlans.jsx` — current plan + day-by-day meals
- `Messages.jsx` — nutritionist conversation thread

## Visual fidelity
Matched to:
- `src/components/ui/*` — Radix-based primitives (button, card, badge, input)
- `src/pages/app/Dashboard.jsx`, `AICoach.jsx`, `MealPlans.jsx`
- `src/components/layout/AppLayout.jsx` and `Sidebar.jsx`
